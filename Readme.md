# Wine Quality MLOps

Proyecto académico para construir un flujo reproducible de clasificación de vinos premium y desplegarlo con herramientas MLOps. El objetivo es predecir `premium = 1` cuando la calidad del vino es mayor o igual a 7, entrenando con vinos tintos y usando vinos blancos para evaluar detección de data drift.

## Documentos del proyecto

- [Especificación](SPEC.md): alcance, contratos y requisitos.
- [Plan](PLAN.md): fases, hitos, ramas y verificaciones.
- [Tareas](TASKS.md): checklist ejecutable por responsable.
- [Reglas para agentes](AGENTS.md): instrucciones de trabajo del repositorio.

## Cómo empezar

1. Lee `SPEC.md`, `PLAN.md` y `TASKS.md` en ese orden.
2. Identifica tu rol y la primera tarea pendiente del bloque actual en `TASKS.md`.
3. Comprueba sus dependencias y ejecuta la verificación indicada antes de marcarla como terminada.

El desarrollo inicia con el esqueleto del repositorio y la documentación CRISP-DM. Los comandos de datos, entrenamiento y servicio se documentarán a medida que se implementen sus tareas.
